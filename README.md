# 🔄 EasyLang Translator

EasyLang Translator is a browser-based code translation tool designed to automatically convert **EasyLang** code into other programming languages.

The project is implemented as a **Chrome Extension** that detects EasyLang code on a webpage and instantly generates the translated version below the original code block.

Currently, the translator supports **EasyLang → Java** conversion, with support for additional programming languages planned for future releases.

---

# 🚀 Project Overview

EasyLang Translator bridges the gap between EasyLang's English-like syntax and traditional programming languages.

The extension automatically:
- Detects EasyLang code on webpages
- Parses EasyLang syntax
- Converts code into Java
- Displays translated code directly below the original source
- Helps users learn how EasyLang maps to real programming languages

# 💻 Example Translation

## EasyLang

```easylang
ask ("Enter your name", name)

print ("Hello ", name)
```

## Generated Java

```java
Scanner scanner = new Scanner(System.in);

System.out.print("Enter your name");
String name = scanner.nextLine();

System.out.println("Hello " + name);
```

---

# ⚙️ How It Works

1. User opens a webpage containing EasyLang code.
2. The extension scans the page.
3. EasyLang code is detected.
4. The parser analyzes the syntax.
5. The translator converts the code into Java.
6. The translated code is inserted directly below the original code block.
